# PetroSoft Frontend

Vite + React + TypeScript frontend for the PetroSoft petrol-pump workflow.

## Install

```bash
npm install
npm run dev
```

The invoice/receipt PDF flow uses `jspdf`, already declared in `package.json`.

## Role navigation

### Admin
- Dashboard
- Customer
- Daily Sales
- Product & Stock
- Tank Management
- Reports
- Account Setup
- User Management

### Manager
- Dashboard
- Customer
- Daily Sales
- Track Petrol Sales
- Lubricant Oil Sales
- Cash Closure

Cash Closure is intentionally manager-only.
